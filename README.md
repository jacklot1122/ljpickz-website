# LJ Pickz Website

A high-converting landing page for LJ Pickz - #1 Data-Driven Sports Investing Group.

## Features

- 🎯 Modern, dark-themed design
- 📱 Fully responsive (mobile-first optimization)
- ⚡ Fast loading static assets
- 🔄 Countdown timer with localStorage persistence
- 📊 Animated stats and testimonials
- 💳 Whop integration for payments

## Tech Stack

- HTML5, CSS3, JavaScript
- Node.js + Express (for serving)
- Railway-ready deployment

## Local Development

```bash
# Install dependencies
npm install

# Start server
npm start

# Visit http://localhost:3000
```

## Deployment

This project is configured for Railway deployment:

1. Connect your GitHub repo to Railway
2. Railway will auto-detect the Node.js app
3. Deploy automatically on push

## Environment

- Node.js 18+
- Port configured via `PORT` env variable
